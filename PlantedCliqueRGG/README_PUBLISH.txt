INTERACTIVE RESEARCH / PLANTED CLIQUE IN RGG -- v24

The file index.html is a self-contained, interactive website.

Temporary publication on GitHub Pages:
1. Create a public GitHub repository (e.g. interactive-research).
2. Upload index.html to the repository root (other files are optional reproducibility data).
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. Once published, use the HTTPS address provided by GitHub Pages.
5. In Google Sites, choose Pages > + > Full-page embed and paste the HTTPS URL.
   Alternatively Insert > Embed > By URL.
6. Publish the Google Site.

Note: Google Sites may put the content in an iframe. A full-page embed is recommended
for interactive content with its own navigation and sticky elements.
You can also use a simple Google Sites hyperlink that opens GitHub Pages directly.

Research content, lab code and simulations unchanged.
